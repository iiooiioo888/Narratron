# Player — 播放器

| 項目 | 值 |
| :--- | :--- |
| 英文代號 | `Player` |
| 中文名 | 播放器 |
| 狀態 | 僅文件 |
| 上游 | `Map` |
| 產出 | 預覽 `Muxer` 合流後的成品 |

## 職責

播放經 `Muxer`（Light Core + FFmpeg）合成的影片，供檢查因果連續性與情緒節奏。

## 同名消歧（強制）

此檔是**用戶層播放器**。外掛 P9 `Player` 是**配樂**，路徑為 `narratron/plugins/player.py`。兩者代號同為 `Player`，必須用命名空間區分，不得合併或改名。

## 凍結契約

- 前端不得直接改檔名為 `Preview`、`Viewer`。
- 配樂由 P9 在生成後寫入音軌，播放器只播合流結果。
