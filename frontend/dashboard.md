# Dashboard — 總覽

| 項目 | 值 |
| :--- | :--- |
| 英文代號 | `Dashboard` |
| 中文名 | 總覽 |
| 狀態 | Alpha Q1 已通 |
| 上游 | `Timeline` |
| 下游 | `Map` |

## 職責

專案級總覽：實體數量、分鏡進度、算力池占用（`Big Core` / `Mid Core` / `Alt Core` / `Light Core`）、外掛觸發摘要、Alpha KPI（連續性誤差）預留面板。

角色護照（`.charpass` / `Character Passport`）是 **Dashboard 內的角色檢視子面板**，不是獨立路由、不新增畫面代號。聚焦時快捷鍵：`S` 儲存、`E` 導出、`I` 導入。

## 凍結契約

- 畫面代號必須是 `Dashboard`。
- 成本與路由資訊來自 P7 `Router` 與 `Scheduler`，前端不得自行發明池名。
- 禁止把角色工坊做成第六個用戶層畫面。
