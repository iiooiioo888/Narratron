生圖設定（WAN／OpenAI／Qwen Edit）

設定第三方生圖 API；儲存後僅供本面板「生成圖片」使用，不開放公開 API 直連。

wan＝阿里百煉；openai＝OpenAI 相容；qwen_edit＝Qwen Image Edit 2511+LoRA（需本機 7860）；http＝自訂 webhook；null＝只組 prompt。

變體／生圖

依選中角色按需排入生圖任務。相同年齡／情緒／場景會命中 character_variants 快取，不會重跑。

建議流程
  1. 左側清單點選角色（ID 自動帶入）
  2. 填入目標年齡，以及可選的情緒／場景／天氣／傷痕
  3. 按「生成所選變體」：只生成該組合；已有快取則直接回傳
  4. 需要整段圖庫時，才勾選補齊並填起始／結束歲數
