Sprint 1
📊

佇列中心 Queue

年齡軸 pipeline：1–80 歲逐步生圖，一次一張，完成自動入庫再接下一步。

Alpha Q1
🕸️

因果圖 Causal Graph

視覺化 Trace Log 因果鏈：實體 → 痕跡 → 分鏡的有向圖，支援互動式探索。

Alpha Q2
🛡️

守護器 Keeper

因果鏈驗證與連續性檢查，確保每一幀的傷痕、道具、服裝邏輯一致。

Alpha Q3
🎥

執行器 Runner

呼叫影片生成模型（Wan2.1 / LTX），將分鏡序列渲染為實際影片片段。

Alpha Q4
🎞️

合流器 Muxer

將多個鏡頭片段合成為連貫的完整影片，自動處理轉場與音訊同步。

📝 劇本解析 Parser

Alpha Q1 · 已完成

貼上劇本文字，Parser 會自動提取角色、道具、場景實體，初始化 State Vault 並記錄因果鏈。 支援中英文混合劇本、場景標記（INT./EXT.）、角色列表、參考圖 URI 等格式。

支援格式：場景標記 (INT./EXT.)、角色/道具/場景區塊、參考圖 ![alt](url)、中文對話格式
